PROBABLY FINE — CYBER CATS EDITION (V2)

QUICK START
1. Extract this ZIP into a folder.
2. Open index.html in your browser.
3. Add teams using the Team name input above the scoreboard.
   Use Rename / remove teams to replace the example names.
4. Read How to play for the 35-minute schedule and rules.
5. Start the game clock when your session begins.

No installation or ChatGPT login is needed for this downloaded copy.
Keep all files and the assets folder together.
The game works offline; its fonts are bundled in assets/fonts.

CAT MODE
A separate visual edition with two kawaii cyber-cat mascots, pastel
question tiles, teams and terminal details. Question content and
scoring match the original game. It uses separate browser storage.

PROJECTOR MODE
Shows the question board, mascots, teams, scores and timers more compactly.
Cat scenes appear inside the Lightning, Final Incident and How to Play
description boxes. The board keeps its small cat banner.
The decorative terminal types commands, shows loading and results, then loops.
Reduced-motion preferences show a static terminal instead.
Exit projector mode to use the inline Add team input. Rename / remove
teams remains available in projector mode.

STORAGE AND RESET
Scores and teams save in this browser, not across devices.
Reset everything beside Leaderboard starts a fresh game, clearing scores,
played questions and custom team names, resetting timers and opening the board.
Export scores saves a CSV copy.
Local-file storage varies by browser. Moving folders or changing browsers
may start fresh. If needed and Python 3 is installed, run in this folder:
  python3 -m http.server 8000
Then open http://localhost:8000

EDITING AND HOSTING
Edit data.js for questions, answers and explanations.
Edit style.css for appearance and app.js for behaviour.
Upload all website files and the assets folder to any static web host.

This is a single-screen host game. Teams answer in the room;
players do not join or submit answers from phones.

VISUAL FINAL INCIDENT
The final challenge uses an invoice image and a payment-queue image,
a shorter Slack report and three concise decision prompts. Detailed
judging guidance remains behind the reveal button.

TIE-BREAK — VERBAL BUZZER
Use the Tie-break tab or the leaderboard button after final scores.
Choose the tied teams and match format:
- Best of 3 (default): first to 2 correct answers.
- Best of 5: first to 3 correct answers.
Host reads a question and says GO. The first team to shout its name or
beep gets the ONLY answer. Host clicks that team; a 10-second answer
clock starts. Reveal and mark correct (+1 win) or incorrect (no point).
No steals. A miss moves to a fresh question, so extra questions may be
needed. Nobody buzzed? Skip to a fresh question. There are 15 questions.
Main game scores stay unchanged. Reset everything clears the tie-break.
