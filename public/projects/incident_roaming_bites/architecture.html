Scope of this map: the evidence identifies the Campaign Assistant as an application and shows the AWS services it calls, but it never identifies how its web tier or business database are hosted. Those parts are therefore shown as logical Roaming Bites components rather than being labelled as API Gateway, Lambda, CloudFront, DynamoDB or another guessed implementation. This does not mean a web host or database is absent—only that participants do not need an invented service choice to investigate this incident.
